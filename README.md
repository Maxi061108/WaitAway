# WaitAway
Wir entwickeln eine App, die Patienten über aktuelle Wartezeiten und Verzögerungen in Arztpraxen informiert. Sie zeigt an, wann Patienten voraussichtlich in der Praxis erscheinen sollten, um unnötige Wartezeiten zu vermeiden. Arztpraxen können die Wartezeiten digital verwalten und Patienten informieren.
